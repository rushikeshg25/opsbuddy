PathBeforeAfter

Membership microbenchmark, Apple M1, Go: original 10,000-item scan 7,296 ns/op; registration map check 37.51 ns/op. About 195× faster for this isolated operation. The map benchmark allocated 64 B/op; the scan allocated none. This does not predict full-service throughput.

Explore the SDK’s queue limit

If ingestion stops responding, captured logs wait in memory. The new queue keeps at most 10,000 records. Extra records are dropped and counted.

Evidence and limits

What was verified
  • All six Go modules compile and pass their available tests. Ping tests pass the race detector.
  • Four SDK tests cover batching, concurrent flushes, retry retention, queue saturation, circular values, and invalid configuration. SDK type checking and package builds pass.
  • Two UI log-parser tests, TypeScript checks, and the Next.js production build pass.
  • PostgreSQL 17 integration tests cover overlapping, clipped, ongoing, and absent incidents. The index migration ran twice on disposable ordinary tables.
  • Browser checks used synthetic API data: desktop, 390 px and 320 px layouts, service search, pagination, log filtering, tab keyboard controls, token reveal/copy, suggestions, and service creation.
What still needs deployment testing
  • Docker was unavailable. Kafka, Redis, TimescaleDB hypertables, OAuth, email, and AI integrations were not tested end to end.
  • Apply migrations/001_read_path_indexes.sql off-peak after schema creation. Index creation can block writes. Test on your TimescaleDB version first.
  • Kafka delivery is at least once. A crash after the database commit but before the offset commit can replay a batch. No deduplication key was added.
  • The queue retains failed batches in memory. Process exit can lose queued records, and saturation deliberately drops new records.
  • Measure p95 latency, consumer lag, memory, and error rates with representative traffic before claiming maximum performance.
  • The landing and sign-in routes grew from 115/116 kB to 118/119 kB with the new navigation and theme controls. The monitoring routes became smaller.
